Lofts compared

Which should you choose?

The Forged 755 is the stronger-lofted set — up to 0.5° stronger than the Forged 704.CB on matching clubs. Expect longer carry per numbered iron but a flatter descent angle; gapping at the wedge end is where that shows up.
