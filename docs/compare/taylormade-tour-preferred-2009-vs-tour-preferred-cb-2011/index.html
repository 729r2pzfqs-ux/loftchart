Lofts compared

Which should you choose?

The Tour Preferred CB (2011) is the stronger-lofted set — up to 2° stronger than the Tour Preferred (2009) on matching clubs. Expect longer carry per numbered iron but a flatter descent angle; gapping at the wedge end is where that shows up.
