Lofts compared

Which should you choose?

The 845s Oversize is the stronger-lofted set — up to 1° stronger than the 845s Silver Scot on matching clubs. Expect longer carry per numbered iron but a flatter descent angle; gapping at the wedge end is where that shows up.
