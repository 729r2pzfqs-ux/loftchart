Lofts compared

Which should you choose?

The SQ MachSpeed is the stronger-lofted set — up to 1° stronger than the Slingshot 4D on matching clubs. Expect longer carry per numbered iron but a flatter descent angle; gapping at the wedge end is where that shows up.
