Lofts compared

Which should you choose?

The J33 Forged Cavity Back is the stronger-lofted set — up to 1° stronger than the J33 Forged Blade on matching clubs. Expect longer carry per numbered iron but a flatter descent angle; gapping at the wedge end is where that shows up.
