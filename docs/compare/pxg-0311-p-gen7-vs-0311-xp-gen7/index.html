Lofts compared

Which should you choose?

The 0311 XP GEN7 is the stronger-lofted set — up to 3° stronger than the 0311 P GEN7 on matching clubs. Expect longer carry per numbered iron but a flatter descent angle; gapping at the wedge end is where that shows up.
