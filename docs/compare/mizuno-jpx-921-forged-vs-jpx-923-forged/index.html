Lofts compared

Which should you choose?

The JPX-923 Forged is the stronger-lofted set — up to 1° stronger than the JPX-921 Forged on matching clubs. Expect longer carry per numbered iron but a flatter descent angle; gapping at the wedge end is where that shows up.
