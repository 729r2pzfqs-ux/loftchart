Lofts compared

Which should you choose?

The TP CB is the stronger-lofted set — up to 2° stronger than the Tour Preferred MC (2014) on matching clubs. Expect longer carry per numbered iron but a flatter descent angle; gapping at the wedge end is where that shows up.
