Lofts compared

Which should you choose?

The Vapor Pro Combo is the stronger-lofted set — up to 1° stronger than the VR Pro Combo on matching clubs. Expect longer carry per numbered iron but a flatter descent angle; gapping at the wedge end is where that shows up.
