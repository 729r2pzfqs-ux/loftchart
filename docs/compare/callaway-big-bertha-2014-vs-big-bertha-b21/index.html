Lofts compared

Which should you choose?

The Big Bertha B21 is the stronger-lofted set — up to 1.5° stronger than the Big Bertha (2014) on matching clubs. Expect longer carry per numbered iron but a flatter descent angle; gapping at the wedge end is where that shows up.
