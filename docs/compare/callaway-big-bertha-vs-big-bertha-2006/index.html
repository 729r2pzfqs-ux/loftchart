Lofts compared

Which should you choose?

The Big Bertha (2006) is the stronger-lofted set — up to 1.5° stronger than the Big Bertha on matching clubs. Expect longer carry per numbered iron but a flatter descent angle; gapping at the wedge end is where that shows up.
